# Передача контекста: посадочные страницы Drive Travel

## Клиент и задача
- Drive Travel (ООО «Трэвэл Экспириенс Руссланд», РТО 024756) — премиальные автотуры по России. Бывший Porsche Travel Experience Russia.
- Основной сайт drive-travel.ru (Tilda) не трогаем: клиент дважды откатывал редизайны. Делаем отдельные посадочные страницы под рекламу, по одной на тур.
- Аудитория из России, 68% с телефона, ядро 35–44 года, в основном семейные пары. Главная проблема: новый покупатель не понимает, за что платить 0,8–1,9 млн ₽.
- Контакты: телефон +7 (921) 891-19-11, менеджер Виктория, WhatsApp wa.me/79218790911 (номер с их сайта — уточнить).

## Жёсткие ограничения
- Ни слова «Porsche», никаких гербов, номеров и надписей #PorscheTravelRussia на фото: у клиента запрет на прямую рекламу бренда. Модели (Cayenne, 911 Safari) называть можно.
- Не придумывать факты (места в заезде, отзывы, условия оплаты). Всё берём с drive-travel.ru или из КП.

## Что сделано
- Генератор: `tours/*.json` → `npm run build` → `dist/<slug>/index.html`. Шаблон `src/template.mjs`, стили `src/styles.css`, скрипт `src/app.js`. Подробности в README.md.
- Страницы: Заонежье (видео на первом экране), Байкал (фото с ретушью), Дагестан, Алтай, Соловки, Арктика, Сахалин, Анапа (у последних шести вместо фото заглушки). Есть A/B-вариант `zaonezhie-price` (с ценой); по умолчанию цена скрыта.
- Стиль «poster»: красные двойные полосы, вертикальное название тура, шрифт SK Porsche для крупных надписей (лицензия не проверена), Onest для текста. У каждого тура своя палитра (`palette` в JSON).
- Квиз из 3 шагов, панель кнопок снизу на телефоне, цели Метрики, временная навигация между турами внизу страниц.

## Где посмотреть и как публикуется
- Ветка с исходниками: `claude/zaonezhie-landing`. Собранный сайт: ветка `site` (в ней плашка «Прототип» и noindex).
- SourceCraft (Яндекс) зеркалит GitHub и публикует ветку `site` (`.sourcecraft/sites.yaml`): https://vanykrasnikov.sourcecraft.site/travell/ (название репозитория уточнить).
- Прототип на claude.ai: https://claude.ai/artifact/YTqndGwHBdba9XvykyuDm4

## Что осталось / открытые вопросы
- Подключить заявки: `leadEndpoint` в `site.config.json` (вебхук amoCRM). Пока заявки никуда не уходят.
- Счётчик Метрики (`metrikaId`), личные Telegram/MAX Виктории.
- Фото для 6 туров без фото; исходники для чистой ретуши Байкала; права на фото, видео и шрифт SK Porsche.
- Уточнить у клиента: число машин в заезде (везде стоит 6), даты Сахалина (7 дней, а заезд 7–15 августа), тексты «Что будет, если…» для новых туров, условия оплаты и отмены.
- Перед рекламой убрать временную навигацию (`allTours` в `build.mjs`) и плашку прототипа.
