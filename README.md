# Drive Travel — посадочные страницы под трафик

По одной странице на тур. Основной сайт drive-travel.ru не трогаем. На страницах нет ни слова Porsche и нет герба; модели (Cayenne, 911) называть можно.

```
npm run build   # tours/*.json -> dist/<slug>/index.html
npm run serve   # сборка + http://localhost:8080/<slug>/
```

## Как сделать новую страницу
Скопировать `tours/zaonezhie.json` под другим `slug` и заменить данные. Копию для A/B-теста делают так же: тот же тур, другой `slug`, другие заголовок и первый экран.

## Что заполнить перед запуском
- `site.config.json`
  - `leadEndpoint` — куда отправлять заявку (вебхук amoCRM или свой обработчик). Пока поле пустое, заявка только пишется в консоль браузера.
  - `metrikaId` — отдельный счётчик Метрики для посадочных страниц. Вебвизор и цели включаются автоматически.
  - `messengers.telegram` / `messengers.max` — личные контакты менеджера. Пустая ссылка — кнопки нет.
  - `privacyUrl` — ссылка на политику конфиденциальности.
- `tours/*.json`
  - `departures[].status`: `open` | `few` (+ `left`, число свободных машин) | `full`. Ставить только реальные цифры.
  - `reviews: [{ "text": "...", "author": "..." }]` — блок отзывов появится, когда здесь будет хотя бы один отзыв.
  - Фото сейчас берутся со страницы drive-travel.ru/snow на Tilda. Перед запуском заменить на свои файлы и проверить, что на снимках не видно гербов.

## Цели Метрики
`cta_hero`, `cta_departure`, `cta_program`, `cta_dock`, `quiz_step_1..3`, `lead`, `phone`, `messenger_*`.
